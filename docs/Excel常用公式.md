# Excel 常用公式与 Power Query

> 运营的日常：每月一行行对数字。下面这些是我反复用到的，按「多久用一次」排序。

## 一、多条件求和：SUMIFS（用得最多）

```excel
=SUMIFS(明细!$D:$D, 明细!$A:$A, $A2, 明细!$B:$B, "<="&$B$1, 明细!$B:$B, ">"&$B$1-30)
```

- 参数顺序是 **求和列在前**，然后是成对的「条件区域, 条件」。和 `SUMIF` 反着，别记错。
- 日期区间要用 `"<="&单元格` 拼字符串，直接写 `"<="&DATE(...)` 也行。
- **整列引用（`$D:$D`）比 `$D$2:$D$10000` 慢很多**，数据超过几万行时改成有限范围。

## 二、查值：XLOOKUP 优先，VLOOKUP 慎用

```excel
' 推荐
=XLOOKUP($A2, 商品!$A:$A, 商品!$C:$C, "未找到")

' 多条件查值（用 & 拼关键字）
=XLOOKUP($A2&$B2, 商品!$A:$A&商品!$B:$B, 商品!$C:$C)
```

| | VLOOKUP | XLOOKUP |
|---|---|---|
| 被查列位置 | 必须在查找列右边 | 任意 |
| 找不到时 | `#N/A` | 可指定默认值 |
| 插入列 | **公式会错位** | 不受影响 |
| 反向查找 | 要配 `IF({1,0},...)` | 直接支持 |

> Excel 2019 及更早版本没有 XLOOKUP，用 `INDEX + MATCH`：
> `=INDEX(商品!$C:$C, MATCH($A2, 商品!$A:$A, 0))`

## 三、同比 / 环比 / 达成率

```excel
' 环比（vs 上期）
=IFERROR(C2/B2-1, "")          ' 同比同理，B 换成去年同期

' 达成率
=IFERROR(D2/E2, "")            ' 目标为 0 时返回空，别显示 #DIV/0!

' 缺口（正数=超额，负数=欠）
=D2-E2

' 带箭头的展示
=IF(C2>=0, "▲", "▼") & TEXT(ABS(C2), "0.0%")
```

**三条纪律**：

1. 所有除法外面套 `IFERROR`，否则报表里全是 `#DIV/0!`。
2. 百分比列统一设置成 `0.0%` 格式，别用 `TEXT` 转成文本 —— 转完就不能再参与计算了。
3. 达成率超过 150% 或低于 0% 时，检查一下分母是不是搞错了。

## 四、Power Query：三个高频操作

运营的表 90% 是「一个文件夹里 30 个格式一样的日报」，手动复制粘贴是浪费生命。

### 1. 合并整个文件夹的表

`数据 → 获取数据 → 从文件夹` → 选目录 → **合并和加载**。
之后每月把新文件丢进那个目录，右键刷新就完事。

关键是**文件名里的日期要能解析出来**：合并后在查询里加一列

```
= Date.From(Text.Select([Name], {"0".."9"}))
```

### 2. 逆透视（宽表转长表）

「日期 × 商品」的宽表几乎没法做透视分析。选中要转的日期列 → `转换 → 逆透视列`，两列名字改成「日期」「数值」。

### 3. 分组聚合

`转换 → 分组依据` → 分组列选「日期」，操作选「求和 → 支付金额」。
等价于 SQL 的 `GROUP BY`，但会保留原始查询，随时能回看中间结果。

> Power Query 的查询步骤是可回溯的：哪一步错了点回去改，不用从头做。这是它比公式强的地方。

## 五、数据透视表的三个设置

1. **值显示方式**：「占列汇总的百分比」用来看结构，「差异百分比」直接出环比。
2. **数字格式**：右键值字段 → 值字段设置 → 数字格式，设一次全局生效，别手动改单元格。
3. **切片器 + 时间线**：给日期字段插「时间线」，拖一下就能看任意区间，比做 12 个表快。

## 六、我踩过的坑

| 现象 | 原因 | 解法 |
|---|---|---|
| `SUMIFS` 结果比透视表小 | 条件是文本型数字（左边有绿色三角） | 选中列 → 数据 → 分列 → 直接完成 |
| 日期筛选筛不出来 | 单元格是文本 `"2026/11/20"` 不是真日期 | `=DATEVALUE(A2)` 或分列转成日期 |
| VLOOKUP 全部 `#N/A` | 查找值前后有空格 | `=TRIM(A2)`，或查找时 `TRIM($A2)` |
| 排序后公式全乱 | 用了相对引用 | 改成 `$` 绝对引用 |
| 合并单元格导致透视报错 | 透视表要求单行表头 | 取消合并，补全空白 |
| 文件越用越大、越用越卡 | 整列引用 + 大量格式 | 改成有限范围，清掉多余格式 |
