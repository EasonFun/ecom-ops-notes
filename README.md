# ecom-ops-notes

电商运营的取数笔记：**指标口径、常用 SQL、Excel 公式**。

写给自己的速查本，也写给每个接手报表的新人 —— 大部分「数据对不上」的争吵，其实都是口径不一致，而不是算错。

## 里面有什么

| 目录 | 内容 |

## 一句话原则

> **先定口径，再算数字；对不上账的时候，八成是口径，两成是时区。**

报表里每个指标都该能回答三个问题：

1. 分子是什么？分母是什么？
2. 统计的是「下单时间」还是「支付时间」？
3. 退款是当期冲减，还是回溯原单日期？

## 说明

- 文中的表名（`orders` / `order_items` / `traffic_daily` / `ad_cost_daily` 等）是**示例结构**，请映射到你自己的库。
- 不含任何真实店铺、真实订单或真实金额数据，全部是结构示例。
- 平台页面上的数字和数仓算出来的对不上，先看口径表最后一节「常见对不上账的原因」。
